# /project:compare

Compare two or more LLM models side-by-side.

1. Load or generate profiles for each model
2. Align benchmark scores on a common scale
3. Build a capability comparison matrix
4. Calculate resource requirement differences
5. Produce trade-off analysis and recommendations
6. Output a ComparisonReport with visualizations data

Usage: `/project:compare <model1> <model2> [model3...]`

Focus areas: capabilities, speed, cost, resource requirements, use-case fit.
